REV.13 · 2026-11-02
기존 네 계정 특수지역 순환 경로 보완. REV.12 기반이며 사망 신규 기능은 포함하지 않습니다.

수정 사항
1. 한밭/일반사냥터 이름이 강하게 연속 확인되면 시간 배너만으로 특수지역 사냥을 계속 판단하지 않도록 보완.
2. 직전 사냥 지역보다 앞쪽에 시간이 남은 지역이 있어도 검사·오류 재시도를 반복하지 않고, 직전 지역 만료까지 확인한 뒤 첫 남은 지역으로 연결.
3. 입력 작업의 가림·비활성화 대기가 20초 넘으면 기존 실패·재시도 경로로 넘겨 다른 캐릭터 작업이 계속될 수 있도록 보완. 단순 사냥 관찰은 가림을 만료로 처리하지 않음.
4. 관찰 기록에 마을·일반사냥터 이미지 점수 추가.
5. GUI에 진단 로그 ZIP 저장 추가: 현재 4캐릭터 상태, 최근 로그, 특수지역 판독 결과, 창별 최근 게임 진단 캡처 최대 2장 수집. 설정 파일·Telegram 인증 파일 제외, 로그의 토큰 형태 문자열 가림.

검증: 77개 모의 검사 및 Python 구문 검사 통과. 네 계정 실제 진행 상태는 최신 진단 ZIP으로 확인 필요.
이미지 스코어 기준을 일괄 낮추지 않았으며, 신규 게임 UI/글자 변화는 최신 캡처와 대조해 추가 보완해야 합니다.
사망 신규 기능 작업은 별도 보관: 무료복구 횟수 우선, 소진 후 보유 복구권 사용 요청 반영 예정. 아직 배포하지 않음.

적용: GUI 종료 → ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기 → 아이콘 실행.
REV.13 확인 → 네 창 연결 → 4계정 자동화. START는 누르지 마세요.
멈춤 증상 재현 시 재실행하기 전에 진단 로그 ZIP 저장을 눌러 만든 파일을 대화에 첨부합니다.
현재 사냥 중인 게임 AUTO는 유지됩니다. 기존 설정·예약·가상환경 유지.

캐릭터1 좌상 / 캐릭터2 우상 / 캐릭터3 좌하 / 캐릭터4 우하.
개인 설정·인증 정보·사용자 원본 로그와 진단 이미지는 소스 배포에서 제외합니다.
