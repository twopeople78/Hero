REV.12 · 2026-10-30
특수지역 사냥 중 마을·일반사냥으로 이동하려는 요청 보호.
- 보급 출발 조건을 AUTO HUD만으로 판단하지 않고 일반사냥터/한밭마을 이름과 HUD로 확인.
- 보급 출발은 두 화면 연속 확인 후 미니맵 클릭.
- 특수지역 시간표시가 있고 일반사냥·마을 출발 확인이 없으면 이동 취소 후 현재 사냥 재확인.
- 월드맵의 이동 불가 글자 검출 추가. 제한 화면에서는 목적지·이동 버튼을 누르지 않음.
- 닫기 X까지 검출되면 월드맵만 닫고 현재 사냥 확인으로 연결. X가 불확실하면 추가 입력 없이 중지.
- 강제 이동·이전 재시도에도 보호 적용. 이전 이벤트 복귀 요청은 현재 사냥 보호와 충돌하지 않도록 해제.
- 보급·일반사냥 로그에 캐릭터 및 창 ID 추가.
REV.11 및 REV.9 관찰 방식 유지. 70개 모의 검사와 구문 검사 통과.
제공 사진의 월드맵 검출 0.994, 이동 불가 검출 성공, 닫기 X 검출 0.961.
사진만으로 최초 이동 요청의 발신 작업은 확정하지 않음. 실제 게임 검증 필요.

적용: GUI 종료 → 2번 게임에 열린 월드맵은 오른쪽 위 X로만 닫기.
ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기 → 바탕화면 아이콘 실행.
REV.12 확인 → 화면 위치대로 4개 연결 → 4계정 자동화. START는 누르지 마세요.
현재 특수지역 AUTO는 유지. 게임 재실행 불필요. 기존 설정·예약·가상환경 유지.
