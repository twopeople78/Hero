# Hero · 조선협객전 클래식 네 계정 관리

현재 버전: **REV.5** · Windows / Python 3.11 32비트.

## 다운로드

- **[전체 소스·설치 패키지](Hero_REV5_Source.zip)**: four 소스와 인식 자산, 검사 코드, 바탕화면 아이콘 설치 파일, 실행 파일, 문서 포함.
- **[기존 설치본 REV.5 업데이트](HeroClassic_REV5_Update.zip)**: ZIP의 four 폴더를 C:\HeroClassic에 덮어씁니다. 기존 설정과 가상환경은 유지합니다.
- **[변경 내역](CHANGELOG.md)**

## 실행

전체 소스 ZIP을 C:\HeroClassic에 풀고 Python 3.11 32비트 가상환경을 사용합니다.

```bat
py -3.11-32 -m venv .venv
.venv\Scripts\python.exe -m pip install -r four\requirements.txt
```

Install_Desktop_Icon.vbs를 한 번 실행한 뒤 바탕화면 아이콘으로 관리 GUI를 실행합니다. 관리자 권한 요청을 승인하고 REV.5를 확인합니다.

## 화면과 예약

| 캐릭터 | 위치 |
|---|---|
| 1 | 왼쪽 위 |
| 2 | 오른쪽 위 |
| 3 | 왼쪽 아래 |
| 4 | 오른쪽 아래 |

게임 내부 화면은 각각 800×600입니다. 미니맵과 지역명을 표시해 두고 **화면 위치대로 4개 연결**을 누릅니다. 층·일반사냥터·이벤트 참여는 각 캐릭터 설정에서 저장합니다. 입력은 한 번에 한 게임에만 보냅니다.

- 04:50 보급 / 05:01 기본 특수지역 순회 (한국 시간).
- 버려진 동굴: 매일 16:00~17:00.
- 가덕도왜성: 수요일 제외 20:00~22:00.
- 저주받은 니조성: 수요일 19:00~23:00.
- 기본 순회가 진행 중이면 이를 마친 뒤 이벤트에 참여합니다.

REV.5는 일반사냥 중 자동화를 시작해도 남은 기본 특수지역을 검사합니다. 이미 특수지역이면 현재 사냥을 관찰하고, 기본 지역 만료가 확인되면 설정 일반사냥터로 연결합니다. 추가 충전 사냥 중 프로그램을 다시 켤 때는 해당 캐릭터의 이어받기 모드와 지역을 지정해야 합니다. 숫자 잔여시간 OCR은 구현돼 있지 않습니다.

## 확인된 범위

REV.5 적용 후 네 계정의 정상 진입을 사용자가 확인했습니다. **44개 모의 검사와 Python 구문 검사를 통과**했습니다. 새벽 보급 전체 흐름, 조선왕릉 종료 후 일반사냥 복귀, 16:00 이벤트 전체 과정은 아직 실제 검증 완료로 기록하지 않았습니다.

## 버전 관리

새 REV마다 코드 패키지, 업데이트 ZIP, 변경 내역을 이 저장소에 갱신합니다. 계정별 설정, Telegram 인증 정보, 가상환경, 진단 이미지와 로그는 업로드하지 않습니다.

이 네 계정 버전은 친구 PC의 두 계정 V76을 기반으로 분리한 버전입니다.
