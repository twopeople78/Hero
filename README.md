REV.15 · 2026-11-02
REV.14 누적 업데이트: 메뉴 가림 정리·현재 HUD 변형·불필요한 재순회 보완.

해결 대상: 일반사냥 중 불필요한 특수지역 재검사, 열린 메뉴에 따른 위치 판독 보류, 한밭마을·AUTO HUD 변형 인식.

변경 사항
1. 자동화 시작/AUTO 확인 전에 열린 특수지역·월드맵·전체 메뉴·가방·상점·창고를 구분.
   메뉴와 닫기 버튼을 연속 확인한 경우에만 닫고, 닫힘 연속 확인 후 미니맵 지역·AUTO 재판독.
   구매·보관·입장 확인 대화는 추가 입력 없이 보류. 닫기 미검출은 임의 클릭하지 않음.
2. 일반사냥·보급 출발에서 메뉴 닫기 고정 좌표를 제거하고 실제 X/메뉴 버튼 영상 좌표 사용.
3. 현재 첨부 HUD의 AUTO 켜짐·U 키·한밭마을 글자 변형 추가. 기존 기준 점수는 일괄 낮추지 않음.
   UI 부분만 참조·검사 자료에 포함하며 사용자 원본 화면·개인 설정·로그는 배포하지 않음.
4. 자동화 재시작 시 일반사냥 유지 시간(10:00 이후)에 기본 특수지역 검사 자동 재시작 금지.
   일반사냥이면 유지, 확인된 한밭마을이면 설정 일반사냥터로 연결.
   이미 특수지역 사냥 중이면 계속 관찰. 오전 05:01~10:00 미완료 이어받기·명시적 수동 특수지역 실행은 유지.
   10:00은 시작/재시작 판정 경계이며, 진행 중인 특수지역을 정각 강제 퇴장시키지 않음.
5. 다섯 곳 만료·마지막 지역 종료를 확인하면 오늘 순회 완료 기록을 저장하여 재시작 중복 검사 억제.
   날짜가 바뀌면 전날 완료 기록은 새 순회를 막지 않음. 기록만으로 새 입장/과금을 허용하지 않음.
6. 지난 보급·오전 예약 입장 요청은 대기열 실행 직전 유효 시각 재검사.
   만료 요청은 기존 사냥을 정지하거나 창 전환/이동을 보내기 전에 취소.
7. 제목 표시줄에 관리자 권한 확인 여부 표시, 진단 ZIP에도 실제 관리자 권한 값 추가.
   run_four.py는 UAC 승격 재실행, 게임 입력은 관리자 권한 검사 통과 시에만 실행.

한국 시간 하루 사이클
04:50 일반사냥 → 한밭마을 → 복자할매·주모 보급
05:00 출석창 확인·닫기
05:01 특수지역 5곳 순회 → 이용시간 소진 후(약 10시 이후) 일반사냥
16:00~17:00 버려진 동굴 → 일반사냥
수요일 외 20:00~22:00 가덕도왜성 → 일반사냥
수요일 19:00~23:00 니조성 → 일반사냥 (가덕도 제외)
다음날 반복. 시간은 예약 요청 기준이며 실제 입력은 한 창씩 순차 실행.

적용: GUI 종료 → ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기 → 기존 아이콘 실행·UAC 승인.
제목 REV.15 · 관리자 권한 확인 → 네 창 연결 → 4계정 자동화 켜기.
START는 보급부터 전체 흐름을 직접 실행하는 버튼이므로 현재 사냥 이어받기와 중복 실행하지 않기.
실행 이상이 생기면 GUI를 재시작하거나 연결을 해제하기 전에 진단 로그 ZIP 저장 후 첨부.

검증: Win32/Tk 대체 모의 검사 97개 및 Python 구문 검사 통과.
첨부된 UI 조각으로 AUTO/한밭 판독과 특수지역 메뉴 닫기 검출 확인.
실제 네 게임의 전체 사이클은 적용 후 실행으로 확인 필요. 사망 신규 복구 기능은 아직 미포함.
