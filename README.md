REV.20 · 2026-11-07 · 04:40 보급 및 실패 시 특수지역 예약 유지

확정 일정
- 네 캐릭터 모두 자동화를 켜면 보급 04:40, 특수지역 05:01로 적용.
- 보급에 실패해도 05:01부터 남은 특수지역을 검사·진행.
- 05:01에 아직 시작하지 않은 보급 대기/재시도는 취소하여 특수지역과 충돌 방지.
- 이미 실행 중인 보급은 결과가 확인된 후 특수지역으로 넘김. 구매 중간에 강제로 중단하지 않음.
- 보급 실패 기록 때문에 오전 특수지역 재개를 차단하던 시작 경로 제거.

출발 판독 개선
일반사냥터 이름 0.82 이상 + HUD 표시 0.78 이상을 두 번 연속 확인해 출발.
이전 AUTO 이미지 0.90 기준에만 의존하여 밝기 변화에서 보급이 막히던 문제 보완.
사망·월드맵·시간제 사냥 표시가 있거나 지역/HUD가 불명확하면 새 조건으로 이동하지 않음.
이동 전 inspect 판독 시간 초과/활성화·가림 실패만 최대 두 번, 30초/60초 후 재검사.
재검사는 05:01 전에만 진행. 이동·구매 시작 후 또는 결과 불확실한 구매는 전체 보급 자동 반복 없음.
출발 로그에 일반지역/HUD/시간제 점수, 연속 확인 수, 이동 시작 여부 추가.
REV.19의 출석창 재검사 및 무료 전용 사망복구 기능 포함.

적용
GUI 종료 → ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기 → 기존 아이콘 실행·UAC 승인
→ 제목 REV.20 확인 → 화면 위치대로 4개 연결 → 자동화 켜기.
네 캐릭터 예약 표시가 보급 04:40 / 특수지역 05:01인지 확인하세요.
오늘 이미 지난 04:40 보급을 소급 실행하지는 않습니다. 시작 시 현재 위치를 다시 확인합니다.
현재 실패한 캐릭터가 계속 일반사냥 중이면 해당 탭의 특수지역을 한 번 눌러 남은 순회를 시작하세요. START 중복 실행 금지.

검증
Win32/Tk 대체 모의 검사 135개 및 Python 구문 검사 통과.
진단 캡처 6장 판독 대조: 낮은 HUD 점수의 2·3번 대기 및 4번 실패 화면은 새 조건 통과. HUD 자체가 안 보이는 화면은 차단.
캡처 대조는 실제 클릭·네 계정 전체 하루 순환 성공 검증과 다릅니다. 실제 게임 적용 후 확인 필요.
