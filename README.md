REV.10 · 2026-10-28
평소 관찰만을 목적으로 한 게임 창 전면 전환 제거. 기존 간격 설정과 무관하게 순회하지 않음.
사냥 중 열린 메뉴를 닫기 위한 자동 전면 전환도 제거.
GUI에 평소 창 전환 없음 안내 표시.
자동화 시작 시 위치 확인, 복자할매·주모 보급, 특수지역·일반사냥 이동,
예약 이벤트 진입·복귀 등 실제 작업의 활성화는 유지.
사냥 화면이 이미 노출되고 활성화된 경우 입력 없이 종료 확인은 유지.
다른 업무 창이 게임을 가리거나 비활성화하면 종료 확인 및 다음 지역 진입이 지연될 수 있음.
정확한 잔여시간 OCR이 없어 숨겨진 상태의 종료 시각을 추정하지 않음.
61개 모의 검사 및 구문 검사 통과. 실제 업무 중 전환 여부 확인 필요.
REV.9 미니맵 한밭마을 보조 인식 포함. 1·2번 추가 지도 클릭 원인은 별도 미해결.
