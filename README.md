REV.14 · 2026-11-02
REV.13 누적 업데이트. AUTO 확인 후 다음 창 연결과 하루 예약 사이클 보완.

1. 일반사냥·특수지역·이벤트·기존 사냥 AUTO 복구에서 켜짐 연속 확인 후 공유 작업 대기열을 50ms 뒤 깨워 다음 캐릭터 작업 진행.
   중첩된 입장/보급/복구 작업이 남아 있으면 그 작업이 끝날 때까지 보호. 입장 확인·AUTO 클릭 전에는 넘기지 않음.
2. 자동 연결 작업의 특수지역 검사·입장·일반사냥·순회 시작에 중복되던 3초 시작 대기 제거. 직접 수동 실행의 준비 대기는 유지.
3. 일반사냥/이벤트 공통 AUTO 검사 주기를 900ms에서 300ms로 단축. 켜짐은 두 화면 연속 검증, 꺼짐 재클릭은 기존 시간·횟수 제한 유지.
4. 창 활성화 한 번 대기는 12초에서 6초로 단축. 활성화되지 않은 입력 작업은 누적 8초 뒤 기존 실패·재시도 경로로 양보.
   실패 창 재시도 간격은 유지하여 반복 창 전환 방지. 평소 관찰 전환 간격 설정은 유지.
5. 05:00 출석창 확인을 네 계정 각각 공유 작업 대기열에 하루 한 번 등록. 검증된 출석 제목·닫기 X만 사용하고 닫힘 확인 후 다음 창 진행.
6. 특수지역 AUTO 켜짐도 열린 입장창·특수지역 메뉴가 사라진 실제 HUD에서만 완료 판정.
7. REV.13 순환 판정/대기 해소/진단 ZIP 저장 기능 포함. 사망·경험치/아이템 복구 신규 기능은 포함하지 않음.

한국 시간 공통 사이클
04:50 일반사냥 → 한밭마을 → 복자할매·주모 보급
05:00 출석창 확인·닫기 (나타난 출석창은 각 진행 단계에서도 처리)
05:01 영혼의 동굴 → 부패한 도성 → 행주산성 → 전리품 매립지 → 조선왕릉
약 10시 이후 다섯 곳 이용시간 소진·복귀 확인 → 설정 일반사냥
16:00~17:00 버려진 동굴 → 일반사냥
수요일 외 20:00~22:00 가덕도왜성 → 일반사냥
수요일 19:00~23:00 니조성 → 일반사냥 (가덕도 제외)
다음날 04:50 반복. 특수지역에서 10시 정각 강제 마을 이동은 하지 않음.
시각은 예약 요청 시각이며, 네 계정 입력은 입장/AUTO 확인까지 한 창씩 순차 실행.
기존 캐릭터별 층·일반사냥터·이벤트 선택 설정은 유지. 이벤트 세 항목을 선택해야 전체 일정 참여.

적용: GUI 종료 → ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기 → 기존 바탕화면 아이콘 실행.
REV.14 확인 → 화면 위치대로 네 창 연결 → 4계정 자동화 켜기. START 중복 실행하지 않기.
진행이 멈추면 GUI 재시작 전에 '진단 로그 ZIP 저장'으로 만든 파일을 대화에 첨부.

검증: Win32/Tk 대체 모의 검사 85개 및 Python 구문 검사 통과.
실제 PC에서 네 게임의 하루 전체 사이클·활성화 속도는 적용 후 실행 기록으로 확인 필요.
