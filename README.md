REV.19 · 2026-11-04 · 출석창 지연 표시 및 재검사 보완

REV.18 누적 버전으로, 기존 사망 우선 감지·무료 전용 복구 기능도 포함합니다.
- 05:00 첫 검사 후 30초/1분/2분/4분/8분 시점에 미확인 출석창 재검사.
- 05:00~05:10 자동화 재시작 시에도 출석 검사 등록.
- 기존 화면 순회에서 출석창을 발견하면 공유 대기열로 닫기 작업 등록. 별도의 상시 창 전환을 추가하지 않음.
- 실제 제목/기간 또는 안내문/X를 확인한 뒤 닫기, 사라짐을 연속 확인.
- 출석 닫기 작업은 진행 중인 특수지역·이벤트 관찰 상태를 취소하지 않음.
- 출석 닫힘 확인 후 오전 보급 완료 상태이고 진행 관찰이 없으면 남은 특수지역 검사 연결.
- diagnostics/attendance.log에 출석 클릭·종료 사유 기록.

주의: 보급 실패 자체의 자동 재시도 정책은 이번 수정에 포함하지 않습니다.
보급 실패 상태에서는 출석창을 닫아도 오전 특수지역 예약이 차단될 수 있습니다.
무료 복구는 REV.18과 동일하게 무료만 사용하고, 비용 또는 숫자 판독 불확실 시 보류합니다.

적용: GUI 종료 → 업데이트 ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기
→ 기존 아이콘 실행·UAC 승인 → 화면 위치대로 4개 연결 → 4계정 자동화 켜짐 확인.
현재 남은 출석창은 다음 정상 화면 순회에서 검사합니다. START를 중복 실행하지 마세요.

검증: Windows 입력을 대체한 모의 검사 126개 통과 및 Python 구문 검사.
실제 게임에서 출석창 닫기부터 네 계정 전체 순환 완료까지는 적용 후 확인 필요.
