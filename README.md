REV.16 · 2026-11-02
REV.15 누적 업데이트. 한밭마을 복귀 판정 및 관찰 속도 보완.

1. 한밭마을의 어두운 글자 획을 구분하는 보조 픽셀 마스크 추가.
   미니맵의 제한된 이름 영역에서 기존 참조 글자를 비교하며 유사도 기준을 일괄 낮추지 않음.
2. 순회 관찰 중 한밭마을 이름과 시간표시 없음이 강하게 연속 확인되면 이전 시간표시 관측 기록이 없어도 복귀 재검사 요청.
   가려진 화면·시간표시 부재만으로 종료 처리하지 않음. 다음 입장은 실제 목록의 만료·남은 시간을 검증한 뒤 실행.
3. 자동화 재시작 후 아직 오늘 순회 완료 기록이 없는 한밭마을은 오후에도 남은 기본 특수지역을 확인.
   완료 기록이 있거나 다섯 곳 모두 만료면 일반사냥으로 연결.
   오후에 이미 일반사냥 중이면 기존처럼 불필요한 특수지역 재검사 없이 유지.
4. 관찰 상태만으로 특수지역 사냥 중이라고 표시하지 않음.
   시간표시 확인 / 복귀 확인 중 / 화면 노출 대기 / 사냥 여부 미확정을 나누어 표시.
5. 보이는 복귀 화면의 재검사 간격을 0.9초로 단축하며 연속 검증 조건은 유지.
6. 기본 관찰 창 전환 간격 30초. 기존 60초 설정은 REV.16 첫 적용 때 한 번만 30초로 전환.
   15·20·30·60·120·180·300초 선택 가능. 이후 사용자가 바꾼 간격은 유지.
   간격을 줄이면 이전 긴 대기 시각을 기다리지 않고 새 간격을 적용.
   30초 설정에서 관찰 네 창 한 바퀴는 대기 작업이 없을 때 약 2분. 입장/AUTO 작업은 우선 보호.
7. 진단에 최근 관찰 종류·시각·복귀 연속 확인 수·특수지역 시간 관측 여부 추가.

검증: Win32/Tk 대체 모의 검사 103개 및 Python 구문 검사 통과.
UI 조각을 사용한 한밭마을 판독 → 복귀 연속 확인 → 다음 특수지역 검사 대기 등록 검사 포함.
실제 네 게임 전체 동작은 적용 후 확인 필요. 사망 신규 복구 기능은 아직 미포함.

적용: GUI 종료 → ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기 → 기존 아이콘 실행·UAC 승인.
제목 REV.16 · 관리자 권한 확인 → 네 창 연결 → 4계정 자동화.
관찰 전환 간격 30초를 확인. 더 빠른 확인은 20초 또는 15초로 선택.
마을에 있는 미완료 캐릭터는 남은 시간을 검사하고, 일반사냥 중인 캐릭터는 오후 사냥 유지.
START를 중복 실행하지 않기. 이상 시 재시작 전 진단 로그 ZIP 저장 후 대화에 첨부.
개인 설정·인증 정보·사용자 원본 화면/로그는 배포에 포함하지 않음.

캐릭터1 좌상 / 캐릭터2 우상 / 캐릭터3 좌하 / 캐릭터4 우하.
