REV.18 · 2026-11-02
REV.17 누적 정정. 사용자가 설명한 일괄복구 순서 재분석 반영.

재분석 결과
- 무료복구 버튼을 별도 클릭해야 한다는 근거가 없어 해당 추가 클릭 제거.
- 확인창 무료 차감을 1회로 고정하던 검사 제거. 남은 무료 횟수 이내의 판독 가능한 차감량인지 검사.
- 아이템 사진은 빈 목록 사례다. 아이템이 있는 실제 복구 완료까지 검증됐다고 주장하지 않음.

최종 시퀀스
사망 검증 → 무덤에서 부활 → 부활 확인 → 복구 아이콘 클릭 → 경험치 복구 탭
→ 목록/선택 상태/남은 무료 횟수 확인 → 일괄복구 직접 클릭
→ 확인창 무료 차감 양수·남은 횟수 이내·복구권 비용 0·선택 재화 비용 0 확인
→ 확인 1회 → 결과 확인 → 아이템 복구 탭도 확인 → 좌측 상단 X
→ 복구 아이콘 소멸 확인 또는 무료 불가 항목 기록 → 원래 일반/특수/이벤트 경로 재검증 후 복귀.

무료 전용 정책
- 무료 0회에서는 복구권이 남아 있어도 사용하지 않음. 다이아·다른 재화도 사용하지 않음.
- 목록이 비면 다음 탭 확인. 무료 수단이 확인되지 않은 아이템은 유료 승인 없이 보류.
- 선택량이 무료 한도를 초과해 확인창에 비용이 표시되면 자동 확인하지 않음.
  이때 무료 항목만 자동으로 다시 선택하는 복잡한 목록 조정은 현재 미지원이며 해당 캐릭터 복구를 보류.
- 무료 횟수/확인창 차감량은 확실히 판독된 한 자리 숫자만 사용. 다중 자리·불명확 숫자는 보류.
- 확인 클릭의 전송 결과가 불확실하면 반복하지 않음. 직접 시작하지 않은 확인창도 자동 승인하지 않음.
- 무료가 끝나 미복구 항목이 남으면 아이콘이 남을 수 있음. 완료로 표시하지 않고, 추가 지출 없이 원래 사냥으로 연결.
- 사망을 AUTO/전투로 처리하지 않도록 우선 감지. 해당 계정 기존 이동 요청을 취소하고 부활·복구를 우선 실행.
- 자동화 꺼짐/전체 정지 상태에서는 자동 부활하지 않음. 사망 감지는 실제 화면을 확인할 수 있을 때 진행.

검증: Win32/Tk 대체 모의 검사 124개 및 Python 구문 검사 통과.
첨부된 사망/아이콘/무료 8회/빈 아이템 UI와 비용 0 확인창 참조,
일괄복구 직행·무료 한도 초과 차단·실제 비용 양수 차단·중복 확인 차단·경로 복귀 검사 포함.
여러 건 차감 한도 비교는 합성 UI 검사도 사용. 실제 게임 전체 복구 완료는 적용 후 확인 필요.

적용: GUI 종료 → ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기 → 기존 아이콘 실행·UAC 승인.

START 중복 실행 금지. 이상 시 재시작 전에 진단 로그 ZIP 저장 후 첨부. death_recovery.log 포함.
