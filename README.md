REV.17 · 2026-11-02
REV.16 누적 업데이트. 사망 우선 감지·무덤 부활·무료복구 시퀀스 신규 연결.

최신 복구 정책
무료복구 가능한 횟수만 사용. 무료가 0회이거나 무료복구 수단이 없는 항목은 더 복구하지 않음.
보유 복구권·다이아·다른 재화는 사용하지 않음. 이전 복구권 사용 계획은 이 정책으로 대체.

사망·복구 흐름
1. 실제 사망 제목과 무덤에서 부활 버튼을 검증. 사망 화면은 AUTO 켜짐/전투 중으로 취급하지 않음.
2. 해당 캐릭터의 기존 AUTO·이동 작업/대기 요청만 취소하고 사망 복구를 우선 순서로 등록.
3. 사망 화면 재검증 후 무덤에서 부활 1회 클릭 → 부활 결과 확인.
4. 우측 위 복구 아이콘 검출 → 클릭 → 경험치 복구 탭 확인.
5. 남은 무료 횟수 양수와 항목 확인 → 필요 시 항목 선택 → 무료복구 선택 → 일괄복구 버튼 확인·클릭.
6. 직접 연 확인창에서 무료 횟수 차감 1, 복구권 비용 0, 다른 선택 재화 비용 0, 확인 버튼을 연속 검증 후 확인 1회.
7. 확인창 닫힘과 항목 소멸 또는 무료 횟수 감소를 검증. 남은 무료 항목을 재검사.
8. 아이템 복구 탭도 확인. 빈 목록은 넘어가고, 무료복구 수단이 없으면 복구권/재화 없이 보류.
9. 두 탭 확인 후 좌측 상단 X를 검출해 닫기. 복구 아이콘이 사라졌는지 확인.
   아이콘이 남고 보류 항목이 없으면 제한 횟수 내 재검사. 무료 불가 항목이 남은 경우 이를 기록하고 추가 복구 없이 사냥 복귀.
10. 직전 경로가 일반사냥이면 설정 일반사냥터, 특수지역이면 실제 남은 시간 검사, 이벤트면 유효한 이벤트 예약 흐름에 연결.

실행 조건과 보류
- 4계정 자동화가 켜져 있어야 자동 부활·복구 실행. 전체 정지/자동화 꺼짐 상태에서는 자동 부활하지 않음.
- 가려진 창은 사망으로 추정하지 않으며, 해당 창을 관찰할 수 있을 때 확인. 기존 관찰 간격 설정 유지.
- 숫자/비용/닫기/확인 검증이 불확실하면 해당 캐릭터 복구 보류. AUTO·이동 입력을 차단하고 다른 캐릭터 작업은 유지.
- 직접 시작하지 않은 복구 확인창은 자동 승인하지 않음. 전송 결과가 불확실한 확인 입력은 반복하지 않음.
- 정상 사냥 경로 종류를 로컬에 기록하여 재시작 후 부활 경로 선택에 참고. 실제 입장 허용은 현재 게임 화면 재검증 후 판단.

검증: Win32/Tk 대체 모의 검사 122개 및 Python 구문 검사 통과.
사망 화면 AUTO 오판 차단, 해당 계정 우선 처리, 무덤 부활 1회, 무료 0/양수/판독 불가,
무료 선택과 일괄복구 분리, 무료 8회 UI, 비용 0 검증, 중복 확인 차단, 두 탭과 아이콘 확인,
일반/특수 사냥 경로 연결 및 정지 상태 무입력 검사 포함.
실제 네 게임에서 부활·복구 완료와 전체 일일 사이클은 적용 후 확인 필요.

적용: GUI 종료 → ZIP의 four 폴더를 C:\HeroClassic에 덮어쓰기 → 기존 아이콘 실행·UAC 승인.

START는 중복 실행하지 않기. 수동 복구 확인창은 닫고 자동화에서 새로 시작하도록 하기.
